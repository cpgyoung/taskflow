TaskFlow - менеджер задач
TaskFlow - веб-приложение для управления повседневными задачами с возможностью задавать приоритеты, отслеживать выполнение и сохранять данные в браузере.
Проект создан для практики веб-разработки и демонстрации навыков работы с HTML, CSS и JavaScript.
## Возможности
- Добавление новых задач
- Редактирование названий задач
- Удаление задач
- Установка обычного и высокого приоритета
- Отметка выполненных задач
- Фильтрация задач по состоянию
- Отображение статистики задач
- Сохранение данных между перезагрузками страницы
- Адаптивный интерфейс для компьютеров и мобильных устройств
- Выпадающее меню выбора приоритета с визуальной индикацией
## Используемые технологии
- HTML5 — структура приложения
- CSS3 — оформление интерфейса и адаптивная вёрстка
- JavaScript — логика приложения и обработка действий пользователя
- LocalStorage API — сохранение задач в браузере
- GitHub Pages — публикация приложения в интернете
